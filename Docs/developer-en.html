What is in the scene (GameScene)

The forests, the plants, the rabbits, the rivers and the cave are ordinary objects in the scene: you see them in the Hierarchy and move, delete or duplicate them by hand.

Tools › Nature › 6. Make The Spear ItemMakes the spear item (Resources/spear.prefab) and its icon (ART/Icons/spear.png). Without it the spear recipe stays grey. The models in the hand, in flight and on the ground are made in code.
Tools › Nature › 7. More Rivers (From The Mountains To The Sea)Makes the five new rivers (Assets/Editor/MoreRiversTool.cs). It reads the five routes the author drew (points in world coordinates, kept in Assets/Island/River/RiverGuides.json) and, for each one, finds near the drawn line the way water would take, from a spring high on the mountain down to the sea, keeping clear of the trees, the old river, the miracle stream, the lake, the cave's mouth and the steps. It digs the bed into IslandTerrain.asset (a stony bottom, banks), takes out the trees and plants in the way, makes the water meshes (Assets/Island/River/River_*.asset) and the scene objects under Rivers (each with a River component, lakeRadius 0, riverName). Run again, it first puts back the ground it dug the time before (kept in Assets/Island/River/RiversDug.bytes), so it can safely be run again. Then run Make The Map Picture too.
Tools › Nature › Make The Map Picture (From Above)A camera high above the island takes its picture straight down (trees, mountains, rivers, lake, sea) for the in-game map: Resources/UI/IslandMap.png. Run it again after changing the island.
Tools › Nature › Paint The Ground Under The Trees AgainAfter moving or adding forests: dark ground under the crowns, no grass, ferns and bushes.
Tools › Nature › Remake The Pictures Of The TreesRedoes the far-away pictures of the trees.
Tools › Nature › Make Game Icon (The Island)Photographs the island and uses it as the icon for Android and the PC.

Tools › Mobile › …Android settings, build the APK, build on the connected phone, the fix for the shiny terrain on Android.
The tools change the scene. Save the scene after them; if you don't like the result, you can undo it with git.

Quick testing

In the game: Menu › Settings, in the Admin row type the password 1212 and press Unlock (then Admin settings). The TEST panel stays unlocked until you close the game; players don't see it without the password. There you can change the hour (sunrise, day, sunset, night), the speed of time (x1…x300), the walking speed, the weather and the season. For the levels:

  • Next level – finishes the current level and goes to the next one.
  • Give items – gives stones, sticks, hay, a log and a mushroom.
  • Give item – any item of the game (from the list), 1 or 5 at a time.
  • Immortal – you never lose health, food or water and nothing kills you (kept until you turn it off).

A new game always starts with an empty inventory, and a loaded game has only what was in the save: whatever is put in the scene for tests (the stone axe in Slot1 and QuickSlot1) is removed by InventorySystem.ClearAllItems(), so loading no longer adds extra stone axes.

All 10 levels were played through by an automatic test (doing what a player does for each goal) on 2026-10-28.

The automatic tests live in the AutoTests/ folder, outside Assets: Unity doesn't compile them and nothing runs by itself. To use them, copy them back into Assets (see AutoTests/README.md), then take them out again. For the rivers there is the Rivers job (also in AutoTests/README.md).

How to add a new level

  1. In Assets/Scripts/Story/StoryManager.cs, in the LevelsEn list (and the same in LevelsRo, in Romanian), add a new Level { … } before the level "THE RAFT" (the raft stays last, now level 10). It has: the title, the story lines, the steps, a hint and the closing text.
  2. In the Status() function each level has a case with its number, which says which steps are done. Add a case for the new level and move the numbers of the levels after it up by 1 (the raft uses Levels.Length, so it moves by itself).
  3. If the level needs to remember something (like "read the journal"), add a field to StoryData.cs; it is saved automatically.
  4. The Help screen reads the levels straight from StoryManager, it doesn't need changing.

Good to know

  • The .meta files are ignored by git: if you move the project to another computer, the scene's references are lost. Copy the whole folder, not only what is in git.
  • The scene is about 46 MB (many nature objects).
  • On Android the terrain textures must be ETC2 RGB (no alpha), otherwise the ground under the forests looks shiny / greenish.
  • The Enviroment object is not at the world's origin: new objects put under it need positions in world coordinates.
  • The game's icon: Assets/ART/Icons/AppIcon.png (and the Android version, with a separate background).
  • In the editor (not playing) the terrain uses Unity's own shader: the rock of the mountains shows only when the game runs.
  • Keep Assets/Island/River/RiversDug.bytes together with the terrain: from it Tools › Nature › 7 puts back the ground it dug the time before, before it digs again.
